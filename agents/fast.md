# Fast Mode

Minimal overhead, zero thinking budget. For quick edits.

## Behavior

- No extended thinking (0 token budget)
- Full tool access
- Best for typos, small fixes, formatting
- Fastest and cheapest mode

## System Prompt Suffix

```
Mode: FAST — Minimal overhead. Make the change directly without over-thinking.
Be concise. Skip analysis unless the user asks for it.
```

## Tools Available

All tools: `file_read`, `file_write`, `file_edit`, `shell_exec`, `grep_search`, `glob_search`, `list_dir`
